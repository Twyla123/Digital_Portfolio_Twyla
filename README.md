# Portfolio site

Source for **https://twyla123.github.io/Digital_Portfolio_Twyla/**, served by GitHub Pages from `main`.

Static HTML and CSS, no build step and no dependencies.

```
index.html                        homepage: research, experience, coursework
projects/bank-distress.html       project page for the bank distress work
styles.css                        shared tokens and layout for both pages
assets/rural_outpatient_trend.png chart generated by the rural hospital pipeline
```

Every figure quoted on the project page names the file that produces it. The research code lives in
its own repositories, linked from the homepage:
[Bank-Distress-Research](https://github.com/Twyla123/Bank-Distress-Research) ·
[Honors_Thesis_Project](https://github.com/Twyla123/Honors_Thesis_Project) ·
[Rural-Hospitals-Project](https://github.com/Twyla123/Rural-Hospitals-Project)

To preview locally: `python3 -m http.server 8765` and open `http://localhost:8765/`.
